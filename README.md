## 启动方式

在本项目目录打开终端：

```sh
source .venv/bin/activate
python -m uvicorn main:app --reload
```

完成练习后访问 http://127.0.0.1:8000/health，预期返回：

```json
{"status": "ok", "message": "学习系统已启动"}
```

网页首页：http://127.0.0.1:8000/。首页使用相对路径读取 index.html，请在本项目目录启动。

交互文档：http://127.0.0.1:8000/docs。停止服务：Ctrl+C。

重建环境时使用 python3 -m venv .venv，然后运行
.venv/bin/python -m pip install -r requirements.txt。

## 前端路由与修改位置

使用 Hash 路由，父路由 `/app` 共用布局，子页面显示在 `route-outlet` 中；路由切换不重新加载整个网页，也不新增后端路径。

| 界面 | 本地地址 | 内容 |
| --- | --- | --- |
| 学习首页 | http://127.0.0.1:8000/#/app/home | 真实数量统计、在读书籍和功能入口 |
| 资料库 | http://127.0.0.1:8000/#/app/library | 查询、筛选、刷新与状态修改 |
| 新增资料 | http://127.0.0.1:8000/#/app/add-resource | 书名和阅读状态表单 |

默认进入学习首页；旧 `#library` / `#add-resource` 地址会转换到新路由，未知路由显示未找到页面。导航激活态与红色下划线匹配当前路由。切页保留表单草稿和筛选；新增成功后，若仍在新增页则回到资料库。草稿只保留在当前页面会话，刷新不会保存未提交内容。

在 `index.html` 搜索“组件：”定位 HTML/CSS，搜索“交互：”定位脚本；`appRoute.children` 是三个子路由的定义。界面由原生 JavaScript 实现，没有引入前端框架或新的依赖。

路由验证：实际 Chrome 检查共用布局不销毁、三个页面切换、刷新直达、前进后退、草稿与筛选保留、旧地址兼容、未知路由、导航下划线及手机布局；真实 GET 读取当前五条资料。此次新增/PATCH 使用模拟响应检查前端流程，未写入个人数据库，也不作为后端写入验收证据。

## 关键设计约定

- 计划完成与实际掌握分开记录；不自动生成技能掌握百分比。
- 资料统一存储，考研空间按科目与用途筛选。
- 任务计划日期与截止日期分开；延期保留原截止日期。
- 书籍与文件分开；纸质书也可记录。附件与数据库分别存储，备份覆盖两者。
- 归档资料保留历史记录。考试科目可配置，院校要求记录年份及当年官方依据。
- 只建立当前功能需要的数据表。目前已创建 resources 表，列为 id、title、type、status。
